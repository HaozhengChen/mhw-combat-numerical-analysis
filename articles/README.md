# Design Articles

This folder contains qualitative design articles related to the Monster Hunter combat numerical analysis portfolio.

These articles are not the main calculation tools. Instead, they provide design interpretation, player-experience analysis, and broader combat system reflection that complement the numerical modeling work.

## Relationship to the Numerical Analysis Project

The main numerical module of this repository is the Great Sword Skill Priority Recommender.

That tool focuses on:

- damage formulas
- DPS calculation
- skill marginal gain
- hitzone logic
- frame efficiency
- recommendation ranking
- dashboard presentation

The articles in this folder focus on:

- boss readability
- player learning
- combat pacing
- risk-reward structure
- preparation and mastery
- qualitative design interpretation

Together, they show a more complete design perspective:

```
Numerical model → combat system → player behavior → design insight
```

---

## Why Include Design Articles?

For a game numerical design portfolio, formulas alone are not enough.

A numerical designer should also understand how numbers shape player behavior.

For example:

- Hitzone values teach players where to attack.
- Motion values and animation commitment shape risk-reward decisions.
- Skill values influence build choices.
- Monster states change damage windows and combat rhythm.
- Preparation systems connect equipment, items, and boss design.

The articles in this folder show how combat numbers connect to real player experience.

## Portfolio Positioning

This folder supports the portfolio by showing that the project is not only a spreadsheet exercise.

It demonstrates three levels of thinking:

| Level | Example |
| --- | --- |
| Numerical modeling | Damage formula, DPS, skill gain |
| System analysis | Build optimization, hitzones, frame economy |
| Design interpretation | Boss readability, mastery, player behavior |

This is especially relevant for roles such as:

- numerical designer
- combat systems designer
- gameplay systems designer
- technical game designer
